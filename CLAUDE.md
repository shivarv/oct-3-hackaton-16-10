# CLAUDE.md

Housing listings app. React + Vite + TS frontend (`frontend/`), FastAPI + SQLAlchemy 2 + Alembic backend (`backend/`), Postgres 16 in Docker.

## Commands

```bash
docker compose up -d --wait                        # DB (host port 5433)
cd backend && source .venv/bin/activate
uvicorn app.main:app --reload --port 8000          # API
pytest                                             # tests (need DB up and migrated)
ruff check . && ruff format .                      # lint/format
alembic revision --autogenerate -m "msg"           # after model changes
alembic upgrade head
cd frontend && npm run dev                         # UI on :5173
npm run build                                      # also type-checks
npm run lint
```

## Conventions

- All API routes are under `/api`. Each resource gets its own router in `backend/app/routers/` and is registered in `app/main.py`.
- Inject DB sessions with `db: DbSession` (from `app.db`). Don't use `Depends(get_db)` inline (ruff B008).
- ORM models use SQLAlchemy 2 typed style (`Mapped[...]`, `mapped_column`). Pydantic schemas live in `app/schemas.py`, with `from_attributes=True` on read models.
- Schema changes go through Alembic migrations only. Review autogenerated files before applying them.
- Config comes from the root `.env` through `app/config.py`. Never hardcode credentials, and never commit `.env`.
- Frontend: every fetch goes through `frontend/src/api.ts`, with types that mirror the backend schemas. `Numeric` columns (for example `price`) arrive as strings.
- In dev, the frontend uses relative `/api/...` URLs (Vite proxy). Don't hardcode `localhost:8000` in components.

## Gotchas

- Postgres is on **5433**, because a native Postgres may already hold 5432 on this machine.
- If port 8000 is taken, run uvicorn on 8001 and set `VITE_PROXY_TARGET` in `frontend/.env.local`.
- Tests hit the real dev DB, so they must clean up the rows they create.
