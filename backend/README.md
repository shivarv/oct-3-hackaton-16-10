# Backend (FastAPI + PostgreSQL)

## Setup

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
alembic upgrade head
```

Config comes from the **root** `.env` (see `../.env.example`). The DB must be running: `docker compose up -d --wait` from the repo root.

## Run

```bash
uvicorn app.main:app --reload --port 8000
```

- Health: http://localhost:8000/api/health
- Swagger: http://localhost:8000/docs

## Migrations (Alembic)

```bash
alembic revision --autogenerate -m "describe change"   # after editing app/models.py
alembic upgrade head                                     # apply
alembic downgrade -1                                     # roll back one
alembic history                                          # list
```

Always review autogenerated migrations before committing them.

## Tests and lint

```bash
pytest          # needs the DB running and migrated
ruff check .
ruff format .
```

Tests currently run against the dev database and clean up after themselves.
